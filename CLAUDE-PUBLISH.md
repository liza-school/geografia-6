`origin` — `https://github.com/liza-school/geografia-6.git`.

  план і топографічні знаки, напрямки й азимути, висоти й горизонталі.

- У кожному є терміни, короткий конспект, приклади біля понять, врізки
  `cherkasy`, `ukraine`, `life`, `game`, `potter`, `horse`, згортки й усна самоперевірка.

У червоних врізках явно пояснені неточності підручника: матеріал глобуса Бегайма,
скорочення «схід», місце П'юї-де-Дом, точність смартфона, висота очей для окомірного
нівелювання. Окремо наведено оновлення системи висот України на EVRS з 2026 року.
Джерела наведені біля уточнень. Не прибирай ці пояснення заради збігу зі старим текстом книжки.

Перед пушем:

1. Переглянь `git status` і diff, включно з новими файлами. Збережи сторонні зміни,
   якщо вони з'явилися після передачі; додай до коміту лише файли цього завдання.
2. Запусти `node --check` для `p07.js`…`p12.js` і `course/tools/check.js`, потім
   `git diff --check`.
3. У `course/` запусти `node tools/check.js`. Це локальний headless Chrome:
   13 сторінок, усі 48 нових відповідей і їхній прогрес, малюнки, врізки,
   ключові слова, реєстр помилок, ширина 390 px та помилки консолі мають пройти.
4. Перевір робоче дерево й актуальність `origin/main` без втрати локальних файлів.
   Якщо з'явилися чужі коміти чи конфлікти, спершу узгодь їх без force push.

Після успішних перевірок зроби коміт із темою:

Не додавай PDF підручника, тимчасові знімки екрана чи профілі Chrome.

Зроби звичайний пуш у підтверджений GitHub remote. Використай чинну схему GitHub Pages
й дочекайся успішного розгортання саме нового коміту. Не змінюй хостинг або його налаштування
без потреби. Очікувана адреса сайту — `https://liza-school.github.io/geografia-6/`;
перевір її за фактичними налаштуваннями Pages.

`#/l/p07`…`#/l/p12`, завантаження нових JS і 24 зображень. Запусти той самий харнес
