# Географія, 6 клас

Інтерактивний конспект для Лізи за підручником С. Г. Коберніка та Р. Р. Коваленка
(Кам'янець-Подільський: Абетка, 2023). Параграфи 1–4 і підсумковий тест, 44 завдання
з автоперевіркою.

Локально — подвійний клік по `index.html`. Ні сервера, ні збірки, ні інтернету.

* [course/README.md](course/README.md) — що всередині, типи блоків, як додати параграф
* [.claude/skills/geo6-materials/SKILL.md](.claude/skills/geo6-materials/SKILL.md) — правила,
  за якими робиться матеріал

PDF підручника в репозиторій не входить — лежить локально поруч із цією текою.

Перевірка перед тим, як віддавати: `cd course && node tools/check.js`
