# Географія, 6 клас — інтерактивний конспект

Конспект § 1–4 за підручником С. Г. Коберніка та Р. Р. Коваленка (Кам’янець-Подільський: Абетка, 2023).
Текст конспекту — той, про який домовилися: спочатку коротко, далі пояснення з прикладами.
Підручник — база фактів; до кожного параграфа додано **врізку про Черкащину**, **врізку про Україну**,
**приклади з життя**, малюнки з підручника та питання з автоперевіркою.
Мова спрощена під 11 років, кожне означення має поруч приклад із життя, а точне формулювання
підручника лишається в таблиці термінів дрібним курсивом.
Правила, за якими це робиться, лежать у `.claude/skills/geo6-materials/SKILL.md`.

## Запуск

Подвійний клац по `index.html` — і все. Сервер не потрібен: ні Python, ні інтернету.
Прогрес зберігається в браузері (`localStorage`), кнопка скидання — внизу головної сторінки.

Синій блок «Україна»:

* § 1 — чому господарство стоїть саме там: Кривий Ріг, каскад ГЕС, південь, Карпати; екологічні проблеми країни;

* § 3 — Геродотова «Скіфія»: Борисфен, Тирас, Гіпаніс, Танаїс і скіфи на наших землях;
* § 4 — вікінги як варяги, шлях «із варягів у греки», американські рослини в українському господарстві.

Зелений блок «з життя» — 3–4 речі, які дитина може перевірити сама: наліпки на фруктах у магазині,
щоденник погоди, миска піску й миска води на сонці, мʼяч із ліхтариком замість Місяця,
човен, що ховається за горизонтом водосховища, вміст кухонної шафи після 1492 року.

Фіолетовий блок «з гри» — місток через Brawl Stars і Minecraft: карта й кущі як продумана територія,
повтор бою як спостереження, Map Maker як моделювання, координати F3 як градусна сітка,
камера навколо персонажа як геоцентрична модель, Showdown без мінімапи як плавання Колумба.

Червоний блок «увага» — місця, де помиляється сам підручник: цитата з номером сторінки,
як насправді, і що відповідати на уроці. Зараз таких три: геліоцентризм Піфагора (§ 3),
висадка Сміта на Антарктиді та «ХІІІ ст.» у підписі мал. 22 (§ 4).

Малюнки (24 файли в `img/`) узяті з PDF підручника: схеми «Система географічних наук»,
«Джерела інформації», «Методи досліджень», уявлення давніх народів про Землю, карти Ератосфена
й Птолемея, маршрути вікінгів, Марко Поло, Колумба, Тасмана, Кука.

## Будова

```
course/
  index.html            каркас сторінки та підключення скриптів
  css/app.css           оформлення, світла й темна теми
  img/                  малюнки, витягнуті з PDF підручника
  js/engine.js          маршрути, відмалювання блоків, прогрес у localStorage
  js/lessons/p01..p04.js зміст параграфів = дані, без верстки
  js/lessons/test.js    підсумковий тест
  tools/check.js        наскрізна перевірка в headless Chrome
  tools/coverage.json   обов'язковий зміст кожного параграфа (перевіряється автоматично)
  tools/errata.json     реєстр знайдених помилок підручника (теж перевіряється)
```

Перевірка перед тим, як віддавати дитині:

```bash
node tools/check.js
```

## Як додати параграф

Створити `js/lessons/pNN.js`, підключити його в `index.html` і викликати `COURSE.addLesson({...})`.
Урок — список блоків.

| Тип блока | Для чого | Поля |
|-----------|----------|------|
| `text` | конспект і пояснення | `html` |
| `note` | жовта врізка «важливо» | `html`, `title` |
| `cherkasy` | врізка про Черкащину | `html`, `title` |
| `ukraine` | врізка про Україну | `html`, `title` |
| `life` | приклади з життя, які можна перевірити самому | `html`, `title` |
| `game` | те саме поняття мовою ігор (Brawl Stars, Minecraft) | `html`, `title` |
| `potter` | те саме мовою Гаррі Поттера, і чим справжній світ відрізняється | `html`, `title` |
| `horse` | те саме на конях: манеж, вольт, скільки б ішов кінь | `html`, `title` |
| `errata` | помилка підручника | `book` (цитата), `truth` (як насправді), `say` (що казати на уроці) |
| `image` | малюнок з підручника | `src` (файл у `img/`), `caption`, `alt` |
| `gallery` | кілька малюнків поруч | `items: [{src, caption}]`, `cols` (2 або 3) |
| `terms` | таблиця термінів | `items: [{t, d, book}]` — `d` просте пояснення з прикладом, `book` формулювання підручника |
| `summary` | головна думка параграфа | `html` |
| `fold` | згортка | `title`, `html` |
| `quiz` | одна правильна відповідь | `question`, `options`, `answer`, `explain`, `wrong` |
| `multi` | кілька правильних відповідей | `question`, `options`, `answers: [індекси]`, `explain` |
| `order` | поставити по порядку | `question`, `items` (у правильному порядку), `explain` |
| `input` | вписати слово, ім’я чи рік | `question`, `accept: [варіанти]`, `hint`, `placeholder`, `explain` |

Блоки `quiz`, `multi`, `order` та `input` рахуються в прогресі, тому їм потрібен свій `id`
(короткий рядок на кшталт `q1`). Відповідь у полі `input` порівнюється м’яко: регістр,
апостроф, зайві пробіли й крапка в кінці не впливають.
